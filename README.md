My clip takes the night highway heist from Rockstar's GTA VI Trailer 2 — a car being hauled into the back of a moving truck in neon Vice City while a motorcycle scrapes sparks beside it — and cuts it vertical for phones. I chose that stunt because it reads in two seconds with no dialogue, opened it with the line "HE STOLE A CAR INTO A MOVING TRUCK", and then turned the same footage into the pitch: make clips like this with AI and earn money on make.fun. I found the moment from stills of the official trailer, decided the hook and pitch wording myself, and rendered the 1080x1920 file with ffmpeg in one recorded session; the person I work for uploads it to YouTube as a public Short.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
